# 🌱 数学小农场

给孩子用的家庭自用小游戏：**做数学题赚金币 → 在种子商店买种子 → 经营自己的 2×4 小农场**。
纯静态网页（HTML + CSS + JavaScript），无后端、不上传数据，PWA 可添加到 iPad / iPhone 主屏幕全屏使用，离线可玩。

> 旧版（中文 / 英文 / 数学 / 编程 / 圣经五模块）保留在 git 标签 `v0.2.0-legacy`。

## 现在有什么

- **家庭账户**：首次打开起名 + 设置 4 位家长密码，之后在这台设备上直接进入，不再验证。
- **多个孩子**：各自的名字、年龄、头像（12 个自绘头像：6 个人物 + 6 个动物），金币、仓库、农场、做题记录互相独立。选好孩子后进入主界面，之后的一切都绑定这个孩子。
- **数学闯关（5 岁以下）**：听题选卡片（"哪个是 7？"，三张数字卡选一张）和照着写数字（左边示范、右边手写）交替出现，先出 0–9（`data/math.json` 的 `little.max` 可升到 20）。每题两次机会，题目用系统语音朗读，跟随界面语言（中文 / English）。家长区可强制指定"听选 + 描写"或"手写算式"模式。
- **数学闯关（5 岁及以上）**：5 分钟倒计时，24 以内加减法（题目和答案都小于 24）。上方出题，下方两个大手写框（十位、个位），停笔 1.5 秒自动识别判定。答对 +1 金币，答错不扣、可再写一次，第二次对了也 +1、再错显示答案进入下一题。
- **手写识别**：自带一个小卷积网络（用 MNIST 训练，int8 量化约 140 KB），纯 JS 推理，离线可用，不依赖任何库。识别没把握时会提示“再写清楚一点”，不判对错。
- **种子商店**：买种子（番茄、向日葵、草莓、蓝莓、南瓜、樱桃、西瓜、火龙果，价格 4–20 金币，按累计收获次数解锁）、买道具（化肥、杀虫剂），卖果实（总价略高于种子价，赚钱主要还是靠做题）。
- **🏭 食品加工厂**：主界面入口。两个加工位，用收获的原料按配方做成果酱、面包、蛋糕、果汁等 16 种成品（配方在 `data/factory.json`），成品售价是原料的 3–5 倍；加工按真实分钟计，受家长区倍速影响。新增小麦、玉米两种作物。
- **🛏️ 我的房间（独立页面，与农场并列）**：农场页右侧“我的房间”进入；房间页有回农场、杂货店（直接打开家具标签）、仓库、摆家具四个入口。：2.5D 等轴视角，5×4 地砖 + 两面墙（带窗），外面有天空、太阳、飘云、飞鸟和蝴蝶等动态布景，初始只有小床和书桌。在杂货店"家具"标签购买书柜、台灯、地毯、玩具箱、衣柜、海报、床单花色等（15–80 金币）后，点"摆家具"放进房间；点家具可旋转、挪到任意地砖、收回仓库；海报可换墙；点床可换床单花色。所有家具为自绘 SVG 方块拼成。
- **🏪 杂货店**（原种子商店）：种子 / 道具 / 家具 / 卖东西（原料和成品都在这里卖）。
- **2×4 农场（主界面，2.5D）**：与房间同一套等轴引擎绘制，立体土台、围栏、小树；点空地选种子种下 → 每个生长阶段开始要浇水 → 随机长草（点几下拔掉）、长虫（用杀虫剂，不治会减产）→ 成熟后点一下收获进仓库。化肥让当前阶段立刻完成。生长按真实时间：番茄 1 小时 … 火龙果 2 天，关掉 App 也在长；家长区"测试模式"可加速 10/60/600 倍。
- **仓库**：金币、种子、道具、果实（可一键去卖）和做题记录。
- **每日次数上限**：每个孩子每天默认最多开始 2 局数学（家长区可改 1 / 2 / 3 / 5 / 不限）。用完后主界面按钮显示"今天的次数用完了"，点击弹出提示，家长输入密码可临时多解锁一次。
- **中文 / English**：首次设置页和家长区都可以切换界面语言，种子、道具名称一并切换。
- **家长区**：长按主界面右上角 ⚙️ 约 2.5 秒 → 输入密码。可切换语言、管理孩子（含今日已玩次数）、每日次数上限、每局时长、答对奖励、农场时间倍速（测试模式）、导出 / 导入存档、清空数据、检查更新。
- **声音**：全部用 Web Audio 合成（不同场景不同背景音乐 + 点击 / 答对 / 答错 / 金币等音效）。右上角 🔊 一键静音。
- **语音**：小龄模式的题目用系统自带的朗读声音（Web Speech API），自动优先选"增强 / 高级"版本；家长区可试听并指定声音、调语速。Siri 的声音不对网页开放，想要更自然的声音请在 iPad 上：设置 › 辅助功能 › 朗读内容 › 声音 › 中文 / 英语，下载带"增强"或"高级"字样的声音（如婷婷、Ava），下载后在家长区选中。

## 在 iPad / iPhone 上使用

1. GitHub Pages 已开启（master 分支根目录），网址：`https://dhx65521.github.io/hello-world/`
2. 用 **Safari** 打开 → 分享按钮 → **添加到主屏幕**。
3. 以后从主屏幕图标打开即为全屏；第一次打开后会缓存全部文件，离线也能玩。
4. 更新内容后：联网打开，进家长区点 **检查更新**。
5. 建议横屏使用；手写时用手指或 Apple Pencil 都可以。

## 自己改内容

- 出题范围、运算类型、识别阈值、小龄模式最大数字：`data/math.json`。
- 种子价格、生长时间、产量、售价、解锁条件、虫草概率：`data/farm.json`（`nameEn` 是英文名）。
- 加工配方：`data/factory.json`；家具与价格：`data/decor.json`（新增家具画法需在 `js/core/iso.js` 的 DRAWERS 里加一个函数）。
- 界面文字：`js/core/i18n.js`，中英文各一份。
- 每局时长、奖励、扣除、时间倍速：家长区里直接改（存在设备上）。
- 改完文件提交前运行 `node tools/build.js` 更新离线缓存清单。

## 存档与同步

存档只保存在设备本地（localStorage）。换设备时在家长区 **导出存档**（JSON 文件，可隔空投送），在新设备 **导入存档**。
以后若需要多设备自动同步，只需替换 `js/core/store.js` 里的 adapter（例如接 Firebase），游戏逻辑不用改。
